# 规划 Agent 输出：资产清单模板拆解

## 目标

生成一份可长期复用的资产清单模板，覆盖土地与物业两类资产，用于业主直售、内部核验和后续 LinkedIn/推介材料草稿生成。

## 输入要求

- 真实素材：位置、面积、资产性质、证件状态、价格、联系人。
- 证明材料：土地证、产权证、规划文件、照片或测绘图等。
- 缺失资料：标记为“待确认”，不得猜测。

## 字段设计

土地类字段：资产编号、资产类型、位置、土地面积、土地性质、证件状态、规划/用途、道路/配套、报价、币种、可交易方式、资料来源、核验状态、备注。

物业类字段：资产编号、资产类型、位置、建筑面积、土地/房屋权属、证件状态、楼层/户型/用途、当前状态、报价、币种、可交易方式、资料来源、核验状态、备注。

## 验收标准

- 同一模板同时支持土地与物业。
- 所有事实字段有资料来源和核验状态。
- 无真实素材时必须使用“占位示例，数据待核”。
- 模板文件可直接用 Excel 或 Google Sheets 打开。
