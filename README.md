# codex-workspace

这个仓库用于沉淀业主直售资产处置、地产开发经验复用、LinkedIn 国际版运营和 Codex 多 Agent 协作工作流。

## 当前用途

- 记录 Codex 阶段化配置与执行报告。
- 保存资产清单模板、推介材料模板和后续个人 Skill。
- 用 Git 管理每次工作流迭代，便于回溯和协作。

## 合规边界

- 不保存未授权公开的敏感证件原件。
- 所有资产事实必须来自真实素材；没有素材时标注“占位示例，数据待核”。
- LinkedIn 内容只生成草稿，不自动发布、不自动回复私信。
- 登录、验证码、授权、付费和外部发布必须由人工操作。
