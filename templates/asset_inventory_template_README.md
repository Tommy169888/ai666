# 资产清单模板说明

文件：`asset_inventory_template.csv`

## 使用方法

1. 每一行填写一项资产，土地和物业共用同一张表。
2. 土地资产填写 `land_area`，物业资产填写 `building_area`，不适用字段留空。
3. `source_material` 写明资料来源，例如土地证、产权证、测绘图、照片、业主报价单。
4. `verification_status` 建议使用：待核、已核、需补资料。
5. 对外生成推介材料前，必须人工复核位置、面积、性质、证件状态、价格等事实字段。

## English Key Points

- One row per asset.
- Use source-backed facts only.
- Mark missing or sample values as “占位示例，数据待核”.
- Human verification is required before external use.
