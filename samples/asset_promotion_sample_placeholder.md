## 核验清单 Verification Checklist

- 位置已按真实素材核验 / Location verified against source material / ទីតាំងបានផ្ទៀងផ្ទាត់តាមឯកសារពិត
- 面积已按证件、测绘或业主文件核验 / Area verified against certificate, survey, or owner file / ផ្ទៃបានផ្ទៀងផ្ទាត់តាមបណ្ណ ឬឯកសារម្ចាស់
- 土地性质或物业用途已核验 / Nature or use verified / ប្រភេទ ឬការប្រើប្រាស់បានផ្ទៀងផ្ទាត់
- 证件状态已核验 / Certificate status verified / ស្ថានភាពបណ្ណបានផ្ទៀងផ្ទាត់
- 价格与币种已核验 / Price and currency verified / តម្លៃ និងរូបិយប័ណ្ណបានផ្ទៀងផ្ទាត់
- 联系方式已获准使用 / Contact details approved / ព័ត៌មានទំនាក់ទំនងបានអនុម័ត
- 未包含未经支持的投资回报、法律、规划或保证性承诺 / No unsupported investment return, legal, zoning, or guarantee claims / មិនមានការអះអាងដែលគ្មានឯកសារគាំទ្រ
